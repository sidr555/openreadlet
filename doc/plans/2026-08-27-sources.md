# Sources Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let `@openreadlet/lib` read a lib from a public Yandex.Disk folder as well as from a static host, without changing the document format.

**Architecture:** Addressing and transport are split. A `Source` answers "give me the bytes at this path inside the lib"; a single hardened `httpGet` keeps size caps, timeouts, abort forwarding, CORS diagnosis and error mapping in one place; each source decides only which URLs to call and which landing address a redirect may end at. A subscription address names its source with a prefix (`yadisk+https://…`), parsed by string and validated by the existing `assertHttps`.

**Tech Stack:** TypeScript (ESM, `strict`), Vitest, WebCrypto-free — no new runtime dependencies.

**Spec:** `doc/specs/2026-08-27-sources-design.md`

## Global Constraints

- Repository language is **English**: code, comments, documentation, commit messages.
- ESM only. `strict: true`. No `any` without a comment saying why nothing else works.
- No new runtime dependencies. `devDependencies` unchanged.
- Coverage thresholds in `vitest.config.ts` are 70% lines/branches/functions/statements and must not fall.
- `npm run lint` must report zero problems; `npm run typecheck` must pass.
- Target release: `0.3.0`.
- Every task ends with a commit. Branch: `feat/sources`, taken from `origin/main`.

## Scope

This plan covers **the package only**. Adopting it in the reader (`readlet`) — upgrading the dependency, moving covers to blobs, recognising a Disk link in the subscription form — is a second plan that cannot start before `0.3.0` is published, because the reader takes the dependency from npm rather than through a workspace.

```ts
// src/address.ts
import { LibError } from './errors.js'
import { resolveBase } from './paths.js'

export type SourceKind = 'static' | 'yadisk'

export interface Address {
  kind: SourceKind
  /** The https address the source works with, normalised. */
  inner: string
  /** The stored, deduplicating form of the subscription. */
  canonical: string
}

const PREFIXES: Record<string, SourceKind> = { yadisk: 'yadisk' }

/**
 * The prefix is split off by string, never by `URL`. An opaque scheme keeps
 * the whole inner address — userinfo included — in `pathname`, where an
 * origin check sails past it; the allowlist in `paths.ts` exists for that
 * reason and must keep seeing a plain https address.
 */
const split = (address: string): { name: string | null; rest: string } => {
  const plus = address.indexOf('+')
  const colon = address.indexOf(':')

  if (plus === -1 || (colon !== -1 && colon < plus)) return { name: null, rest: address }

  return { name: address.slice(0, plus), rest: address.slice(plus + 1) }
}

/** Two spellings of one public folder must not become two subscriptions. */
const canonicaliseYadisk = (inner: string): string => {
  const parsed = new URL(inner)

  if (parsed.host === 'yadi.sk') parsed.host = 'disk.yandex.ru'

  return `${parsed.origin}${parsed.pathname}`.replace(/\/+$/, '')
}

export function parseAddress(address: string): Address {
  const { name, rest } = split(address)

  if (name === null) {
    const inner = resolveBase(rest)

    return { kind: 'static', inner, canonical: inner }
  }

  const kind = PREFIXES[name]

  if (!kind) {
    throw new LibError('insecure-origin', `Unknown source prefix ${name}`)
  }

  const inner = canonicaliseYadisk(resolveBase(rest))

  return { kind, inner, canonical: `${name}+${inner}` }
}
```

```ts
// src/sources/static.ts
import type { RequestOptions } from '../fetch.js'
import { httpGet } from './http.js'
import type { Source, SourcePayload } from './types.js'

const sameOrigin = (target: URL, landed: URL): boolean => target.origin === landed.origin

/** A lib served as plain files under one origin. The behaviour of version 1. */
export function staticSource(inner: string): Source {
  return {
    base: inner,
    allowsLanding: sameOrigin,

    get(path: string, limit: number, options: RequestOptions): Promise<SourcePayload> {
      return httpGet(`${inner}/${path}`, limit, options, sameOrigin)
    },

    directUrl(path: string): string {
      return `${inner}/${path}`
    },
  }
}
```

```ts
// src/lib.ts — replace the body of openLib
import { parseAddress } from './address.js'
import { aboutPath, bundlePath, feedPath, picPath, testPath, textPath } from './paths.js'
import { sourceFor } from './sources/registry.js'
import type { Source } from './sources/types.js'

export function openLib(address: string | Source, options: LibOptions = {}): Lib {
  const source = typeof address === 'string' ? sourceFor(parseAddress(address)) : address
  const docLimit = options.maxDocBytes ?? DEFAULT_DOC_BYTES
  const textLimit = options.maxTextBytes ?? DEFAULT_TEXT_BYTES
  const picLimit = options.maxPicBytes ?? DEFAULT_PIC_BYTES

  const json = async (path: string, call?: Call): Promise<unknown> => {
    const { bytes, safeUrl } = await source.get(path, docLimit, withCall(options, call))

    return decodeJson(bytes, safeUrl)
  }

  return {
    base: source.base,
    about: async (call) => parseAbout(await json(aboutPath(), call)),
    feed: async (call) => parseFeed(await json(feedPath(), call)),
    bundle: async (id, call) => parseBundle(await json(bundlePath(id), call)),
    test: async (id, call) => parseTest(await json(testPath(id), call)),

    async text(id, call) {
      const { bytes } = await source.get(textPath(id), textLimit, withCall(options, call))

      return new TextDecoder().decode(bytes)
    },

    async pic(id, call) {
      const { bytes, contentType } = await source.get(
        picPath(id),
        picLimit,
        withCall(options, call),
      )

      return new Blob([bytes], { type: contentType || 'image/webp' })
    },

    directUrl: (path) => source.directUrl(path),
  }
}
```

`decodeJson` is the JSON decoding already inside `fetchJson`. Move it into a shared helper so
both callers raise the same `bad-json` with the same redaction:

```ts
// src/fetch.ts
export function decodeJson(bytes: Uint8Array, safeUrl: string): unknown {
  const text = new TextDecoder().decode(bytes)

  try {
    return JSON.parse(text)
  } catch (error) {
    throw new LibError('bad-json', 'Document is not valid JSON', { url: safeUrl, cause: error })
  }
}
```

`fetchJson` then becomes `decodeJson(...)` over an `httpGet` payload, and `fetchLibs` is left
exactly as it is: a catalogue lives at an arbitrary address, stays https-only, and must not
grow source handling in this work.

In `src/index.ts`: drop `picUrl` from the `./paths.js` export list, add `parseAddress`, `staticSource`, and the `Source`, `SourcePayload`, `LandingPolicy` types.

```ts
// src/sources/yadisk.ts
import { LibError } from '../errors.js'
import type { RequestOptions } from '../fetch.js'
import { httpGet } from './http.js'
import type { Source, SourcePayload } from './types.js'

const API = 'https://cloud-api.yandex.net/v1/disk/public/resources/download'

/** The api itself, and the sharded storage hosts a download lands on. */
const STORAGE = /^s\d+[a-z0-9]*\.storage\.yandex\.net$/

const apiLanding = (target: URL, landed: URL): boolean => target.origin === landed.origin

const downloadLanding = (_target: URL, landed: URL): boolean =>
  landed.protocol === 'https:' &&
  (STORAGE.test(landed.host) || landed.host === 'downloader.disk.yandex.ru')

/** The resolve answer is small; a cap is still applied rather than assumed. */
const RESOLVE_CAP = 64 * 1024

/**
 * A public folder is read in two steps: ask the api for a download address,
 * then follow it. The address is never kept. It is pinned to a *version* of
 * a file, and a stale one answers 200 with the previous content — reusing it
 * would turn the protocol's update rule into silent staleness rather than a
 * visible failure.
 */
export function yadiskSource(inner: string): Source {
  const resolve = async (path: string, options: RequestOptions): Promise<string> => {
    const url = new URL(API)
    url.searchParams.set('public_key', inner)
    url.searchParams.set('path', `/${path}`)

    const { bytes, safeUrl } = await httpGet(url.href, RESOLVE_CAP, options, apiLanding)

    let answer: unknown

    try {
      answer = JSON.parse(new TextDecoder().decode(bytes))
    } catch (error) {
      throw new LibError('bad-json', 'The storage answered the resolve with invalid JSON', {
        url: safeUrl,
        cause: error,
      })
    }

    const href = (answer as { href?: unknown }).href

    if (typeof href !== 'string' || href === '') {
      throw new LibError('schema-mismatch', 'The resolve answer carries no href', {
        url: safeUrl,
      })
    }

    return href
  }

  return {
    base: `yadisk+${inner}`,
    allowsLanding: downloadLanding,

    async get(path: string, limit: number, options: RequestOptions): Promise<SourcePayload> {
      const href = await resolve(path, options)

      return httpGet(href, limit, options, downloadLanding)
    },

    directUrl(): null {
      return null
    },
  }
}
```

The 404 mapping needs nothing extra: `httpGet` already turns 404 into `not-found`, and both `DiskNotFoundError` and `NotFoundError` arrive as 404.

`httpGet` starts its own timer per call, so two legs would otherwise spend two timeouts. The
deadline is therefore created once, in `get`, and both legs run under it:

```ts
// src/sources/yadisk.ts — inside get(), replacing the two bare calls
const budget = options.timeout ?? 10_000
const controller = new AbortController()
const timer = setTimeout(() => controller.abort(), budget)
const forward = (): void => controller.abort()

options.signal?.addEventListener('abort', forward, { once: true })

try {
  const legs = { ...options, signal: controller.signal, timeout: budget }
  const href = await resolve(path, legs)

  return await httpGet(href, limit, legs, downloadLanding)
} finally {
  clearTimeout(timer)
  options.signal?.removeEventListener('abort', forward)
}
```

The inner per-call timers never fire first: each is set to the whole budget, while the outer
one has been running since before the first leg started.
